| Variable | Description |
|---|---|
| `PUBLIC_URL` | Public HTTPS URL, no trailing slash |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google OAuth client (Web application), redirect URI `<PUBLIC_URL>/auth/google/callback` |
| `ADMIN_EMAIL` | Google account of the administrator |
| `APP_SECRET` | Secret that encrypts the Intervals.icu keys (`openssl rand -base64 32`); never change it. If empty, a key file is generated in the data volume and included in backups |
| `ATHLETE_AGE` | Initial age of the admin for the max-HR estimate (default `33`); editable later in the profile |
| `SYNC_CRON` | Sync schedule (default `*/15 * * * *`); the app also syncs when opened and with "Sync now" in the profile |
| `BIND_ADDR` / `HOST_PORT` | Host address and port of the app (default `127.0.0.1:3000`) |
| `AAC_TAG` | Image tag: `latest` (default), `staging` or `sha-<commit>` |
| `COMPOSE_PROFILES` | `backup` runs the nightly backups; `docs` also serves this documentation. Remove `backup` only on a test instance |
| `DOCS_PORT` | Host port of the documentation, when enabled (default `3001`) |
| `BACKUP_CRON` / `BACKUP_KEEP_DAILY` / `BACKUP_KEEP_WEEKLY` / `BACKUP_KEEP_MONTHLY` | Backup time and retention (defaults `30 3 * * *`, 7 / 4 / 6) |
| `LOGIN_GOOGLE` | `off` forces single-user mode; the backend then refuses requests coming from the internet |
| `AAC_AMBIENTE` | `staging` shows a **BETA** badge, so a test instance is never mistaken for production |
| `COMPOSE_PROJECT_NAME` / `AAC_PREFIX` | Several instances on one host (containers and volumes named `<AAC_PREFIX>-backend`, `<AAC_PREFIX>-db`…) |
| `STRAVA_CLIENT_ID` / `STRAVA_CLIENT_SECRET` | Strava app for one-tap connection (optional, see [Strava](#strava)) |
| `INTERVALS_API_KEY` / `INTERVALS_ATHLETE_ID` | Single-user mode only: Intervals.icu credentials (they can also be entered in the profile) |

**Push notifications** need no configuration: the VAPID keys are generated on first start and stored encrypted in the system database, which is included in backups.

## Strava

To offer your users the Strava connection (optional):

1. At [strava.com/settings/api](https://www.strava.com/settings/api) create an application: name (e.g. *AAC*), category *Training*, website and, under **Authorization Callback Domain**, the domain of `PUBLIC_URL` without `https://` (e.g. `aac.run`).
2. Copy the **Client ID** and **Client Secret** into `.env`:

   ```bash
   STRAVA_CLIENT_ID=12345
   STRAVA_CLIENT_SECRET=...
   ```

3. `docker compose up -d`: *Connect with Strava* appears in the profile.

A new Strava app can be used **only by its owner** until Strava approves it: to open it to other users, submit it for review through Strava's developer programme. AAC only reads activities (`activity:read_all`), estimates load from heart rate, shows "Data from Strava" with the *View on Strava* link and deletes the activities when a user disconnects Strava.
